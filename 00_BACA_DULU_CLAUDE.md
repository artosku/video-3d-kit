# BACA DULU (untuk Claude)

Folder ini adalah salinan kit video 3D milik pemiliknya. Kalau pengguna hanya meng-upload zip ini tanpa kata apa pun, tugasmu: **pasang semuanya sampai beres tanpa disuruh**.

1. Baca `ZIP_SETUP.md` lalu ikuti langkahnya satu per satu.
2. Baca `KIT_CHANGELOG.md` sekali supaya tahu fitur apa saja yang ada di salinan ini.
3. Jangan `git pull` atau clone ulang repo GitHub di atas folder ini: salinan ini lebih baru dan akan terhapus.
4. Bicara dengan pengguna dalam bahasa Indonesia, poin singkat, maksimal 5 poin per pesan. Jangan minta API key di chat: pengguna menempelkannya sendiri di file `.env`.
